# Prompts utilizados en Huawei MaaS + OpenCode

## Prompt 1: Integración OpenCode + MaaS

"Integra OpenCode con Huawei Cloud MaaS ModelArts. Crea un cliente Python que:
- Conecte con endpoint: https://api-ap-southeast-1.modelarts-maas.com/openai/v1
- Use modelo GLM-5
- Implemente métodos para: chat_completion, code_generation, code_analysis
- Maneje autenticación con API key de forma segura
- Valide respuestas y errores de API
Sigue estándares OpenAI SDK."

## Prompt 2: Generación de cliente MaaS

"Crea un cliente Python robusto para Huawei MaaS con:
- Clase HuaweiMaaSClient que encapsule conexión
- Método chat_completion(messages, temperature, max_tokens)
- Método code_generation(prompt, language)
- Método analyze_code(code)
- Manejo de excepciones y timeouts
- Logging de solicitudes
- Documentación con docstrings
Usa OpenAI SDK como base, compatibilidad completa."

## Prompt 3: Configuración segura

"Diseña esquema de configuración para OpenCode + Huawei MaaS:
- Template JSON de configuración
- Variables de entorno (.env)
- Instrucciones de setup
- Mejores prácticas de seguridad
- Gestión de credenciales
No incluir claves en repositorio. Usar gitignore."

## Prompt 4: Documentación README

"Escribe README completo para solución Hackathon Huawei MaaS:
- Descripción del proyecto
- Prerrequisitos y dependencias
- Pasos instalación detallados
- Configuración OpenCode + MaaS
- Ejemplos de uso con cliente Python
- Troubleshooting común
- Referencias y documentación oficial
Formato markdown, secc iones claras."

## Prompt 5: Validación y testing

"Crea tests para cliente HuaweiMaaSClient:
- Test de autenticación
- Test de conexión a endpoint
- Test de métodos (chat, code gen, analysis)
- Manejo de errores y excepciones
- Mock de respuestas de API
- Validación de formato de requests/responses
Usa pytest, no requiere API key real en tests."
